# IGSA Badminton Season 3

Registration page for the Badminton Tournament Season 3, run by the Indian
Graduate Student Association and the UofL Badminton Club.

**25 and 27 September 2026, 5:00 to 9:00 PM, SRC courts, University of Louisville.**

Live page: https://sudsho.github.io/igsa-badminton/

`index.html` is a single self-contained file. It posts each entry to a Google
Apps Script web app owned by igsa.uofl@gmail.com, which writes it into a Google
Sheet. It is hosted here rather than on script.google.com because that origin
redirects visitors signed into multiple Google accounts to a URL that 404s.
